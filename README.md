Hi, I'm Jackson. I graduated from Georgia Tech in 2026 and work in commercial strategy in New York. Outside of work I build tools for myself, mostly around 3D printing and automating the boring parts of my day. I've been modeling in Onshape for about ten years and print on a Bambu X2D.

### 3D printing

- [layerling](https://github.com/Joconnell04/layerling): send a few photos and a sentence, get back a multicolor 3MF that's ready to slice. Meshy builds the model, Claude decides which filament goes where, and a print simulator checks the result before Bambu Studio does.
- [slicer-lab](https://github.com/Joconnell04/slicer-lab): browser slicers for things Bambu Studio won't do, like conductive multi-material parts, non-planar spirals and textures baked into the toolpath.

### Tools I use every day

- [mailroom](https://github.com/Joconnell04/mailroom): an Apps Script sorts my Gmail into now, later and noise using only sender and subject, and a local Node client is where I read it. My phone only buzzes for mail a person needs me to answer.
- [presage](https://github.com/Joconnell04/presage): a macOS call copilot that transcribes locally and has the answer from my files ready before the question is finished.
- [blueprint](https://github.com/Joconnell04/blueprint): an MCP App for Claude Desktop where you approve the plan for a spreadsheet or deck on a canvas before Claude builds the real file.
- [fantasy-gm](https://github.com/Joconnell04/fantasy-gm): a Sleeper fantasy football assistant with waiver Monte Carlo and a morning brief. It recommends and never touches the roster.

### Raycast

- [binge](https://github.com/Joconnell04/binge): search a title, hit return, mpv opens, with one key for the next episode.
- [vault-raycast](https://github.com/Joconnell04/vault-raycast): save and find API keys in a Notion database.
- [hypersonic-rank](https://github.com/Joconnell04/hypersonic-rank): a fork of Hypersonic that lets me order my to-dos with Shift+Arrow.

Older: [OwnYourChat](https://github.com/Joconnell04/OwnYourChat) syncs ChatGPT and Claude conversations to SQLite, and [kalshiEarningsScannerBot](https://github.com/Joconnell04/kalshiEarningsScannerBot) scores Kalshi earnings-call markets against past transcripts.
